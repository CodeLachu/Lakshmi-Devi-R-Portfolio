# Creative Portfolio Landing Page

A minimal personal portfolio landing page inspired by the supplied reference image.

## Stack

- React
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Customize

Open `src/App.jsx` and replace:

- `Your Name`
- Email address
- GitHub / LinkedIn links
- About text
- Project names and descriptions
- Skills

The visual theme intentionally keeps the reference's:
- warm off-white background
- orange + deep navy typography
- oversized serif hero heading
- minimal rounded buttons
- spacious editorial layout
